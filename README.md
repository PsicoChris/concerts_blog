# Concert Pulse

A modern static blog template for concerts, ready to deploy on GitHub Pages.

## Features

- Responsive HTML/CSS layout
- JavaScript-based post filtering
- Lightweight and GitHub Pages compatible
- Designed for live music, festivals, gig guides, and concert reviews

## Usage

1. Push this repository to GitHub.
2. In the repository settings, enable GitHub Pages from the `main` branch (or `gh-pages` branch) and set the site to `/`.
3. Open the published URL to view the blog.

## Add a new blog post

- Open `posts.json`.
- Add a new post object to the array.
- No additional HTML files are needed.
- Each blog post opens as a detail view on the same page using hash-based routing.

## Customization

- Edit `index.html` to adjust page structure, hero text, or main sections.
- Update `styles.css` for a custom color palette or brand styling.
- Add or update entries in `posts.json` to publish new posts.
